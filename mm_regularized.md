# MM с экспоненциально-линейной регуляризацией логарифмов

Метод `mm_regularized` наследует `DLightSBMM` и использует те же E-шаг
коэффициенты блочных задач и процедуры обучения и сэмплирования

## Целевая функция

\[
F(\theta)=\widehat{\mathcal L}(\theta)
+\frac{\lambda_{\alpha}}{K}\sum_{k=1}^{K}\phi\left(\log\alpha_k\right)
+\frac{\lambda_r}{DSK}\sum_{d=1}^{D}\sum_{s=1}^{S}\sum_{k=1}^{K}\phi\left(\log r_{dsk}\right)
\]

\[
\phi\left(u\right)=e^u-u-1
\]

`regularization_lambda_alpha` задаёт коэффициент среднего штрафа весов смеси

`regularization_lambda_cores` задаёт коэффициент среднего штрафа ядер

Значения по умолчанию равны `0.01` и `0.5`

Нормировка делает масштаб каждого блока независимым от числа его параметров

Оно не эквивалентно `weight_decay=0.01` в AdamW

## Обновление блока

К прежнему мажоранту добавляется тот же нормированный штраф
Для каждой координаты решается задача в логарифмической переменной

\[
u=\log z
\]

\[
\min_u\; ae^u-bu+\lambda\left(e^u-u-1\right)
\]

Для весов используется покоординатный коэффициент

\[
\lambda=\frac{\lambda_{\alpha}}{K}
\]

Для ядер используется покоординатный коэффициент

\[
\lambda=\frac{\lambda_r}{DSK}
\]

При положительном коэффициенте регуляризации минимум единственен

\[
(a+\lambda)e^u=b+\lambda
\]

\[
u_{\mathrm{new}}=\log(b+\lambda)-\log(a+\lambda)
\]

Реализация использует явное обновление через `torch.logaddexp` без бисекции
Для точного вычисления штрафа около нуля используется локальный ряд
Штраф растёт линейно при больших отрицательных логарифмах
и экспоненциально при больших положительных
При нулевой статистике координата остаётся строго положительной
Исходные параметры должны быть строго положительными

## Гарантия убывания

Штраф одинаков в целевой функции и мажоранте поэтому касание сохраняется
Проверка перед принятием шага контролирует обе регуляризованные величины
Неуспешный кандидат не записывается в модель

Гарантия относится к текущему батчу
Отдельный нерегуляризованный loss может увеличиваться

При нулевом коэффициенте соответствующий блок использует исходное обновление MM

## Запуск

```bash
python -m src.run experiment=mm_regularized/benchmark_hd/d16_g002 method.regularization_lambda_alpha=0.01 method.regularization_lambda_cores=0.5
```

Доступны также конфиги d2 и d64
Они наследуют настройки соответствующих экспериментов обычного MM

## Метрики

`train/loss` содержит сумму loss и штрафа

`train/data_loss` содержит исходный loss для сопоставления с другими методами

`train/regularization` содержит значение штрафа

Критерии остановки `tol` и история `fit_mm` используют регуляризованную цель
Валидация и тестирование также возвращают регуляризованный loss
и отдельно логируют `data_loss` и `regularization`

## Повторное использование модели

```python
from src.methods.mm_regularized import DLightSBMMRegularized

solver = DLightSBMMRegularized.from_model(
    model,
    regularization_lambda_alpha=0.01,
    regularization_lambda_cores=0.5,
)
```

```python
history = solver.fit_mm(x0, x1, max_iter=100)
```
