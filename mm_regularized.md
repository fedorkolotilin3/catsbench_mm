# MM с квадратичной регуляризацией логарифмов

Метод `mm_regularized` наследует `DLightSBMM` и использует те же E-шаг
коэффициенты блочных задач и процедуры обучения и сэмплирования

## Целевая функция

\[
F(\theta)=\widehat{\mathcal L}(\theta)
+\frac{\lambda}{2}\left[\sum_k(\log\beta_k)^2
+\sum_{k,d,s}(\log r_k^d[s])^2\right]
\]

`regularization_lambda` задаёт коэффициент перед суммой квадратов
Нормировки на число параметров нет
Значение по умолчанию `0.01` является начальной настройкой для экспериментов
Оно не эквивалентно `weight_decay=0.01` в AdamW

## Обновление блока

К прежнему мажоранту добавляется тот же штраф
Для каждой координаты решается задача в логарифмической переменной

\[
u=\log z
\]

\[
\min_u\; ae^u-bu+\frac{\lambda}{2}u^2
\]

При положительном коэффициенте регуляризации минимум единственен

\[
ae^u-b+\lambda u=0
\]

\[
ae^u+\lambda>0
\]

Реализация использует векторизованную бисекцию с вычислением знака
производной в логарифмическом масштабе
При нулевой статистике координата остаётся строго положительной
Исходные параметры должны быть строго положительными

## Гарантия убывания

Штраф одинаков в целевой функции и мажоранте поэтому касание сохраняется
Проверка перед принятием шага контролирует обе регуляризованные величины
Неуспешный кандидат не записывается в модель

Гарантия относится к текущему батчу
Отдельный нерегуляризованный loss может увеличиваться

При `regularization_lambda=0` используется исходное обновление MM
включая сохранение координат с нулевыми статистиками

## Запуск

```bash
python -m src.run experiment=mm_regularized/benchmark_hd/d16_g002 method.regularization_lambda=0.01
```

Доступны также конфиги d2 и d64
Они наследуют настройки соответствующих экспериментов обычного MM

## Метрики

`train/loss` содержит сумму loss и штрафа

`train/data_loss` содержит исходный loss для сопоставления с другими методами

`train/regularization` содержит значение штрафа

Критерии остановки `tol` и история `fit_mm` используют регуляризованную цель
Валидация и тестирование также возвращают регуляризованный loss
и отдельно логируют `data_loss` и `regularization`

## Повторное использование модели

```python
from src.methods.mm_regularized import DLightSBMMRegularized

solver = DLightSBMMRegularized.from_model(
    model,
    regularization_lambda=0.01,
)
```

```python
history = solver.fit_mm(x0, x1, max_iter=100)
```
