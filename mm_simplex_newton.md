# MM с одним шагом Ньютона для симплексного множителя

## Блочная задача

Для каждой строки параметров решается задача

\[
\min_{z_j > 0}
\sum_j a_j z_j - b_j \log z_j
\]

с приближённым выполнением ограничения

\[
\sum_j z_j = 1
\]

Условие стационарности задаёт параметры через один множитель

\[
z_j = \frac{b_j}{a_j + \lambda}
\]

а множитель определяется уравнением

\[
F(\lambda)
=
\sum_j \frac{b_j}{a_j + \lambda} - 1
=
0
\]

## Явное обновление

Вместо бисекции выполняется ровно одна поправка Ньютона

\[
\lambda^{t+1}
=
\lambda^t
+
\frac{
\sum_j \dfrac{b_j}{a_j + \lambda^t} - 1
}{
\sum_j \dfrac{b_j}{\left(a_j + \lambda^t\right)^2}
}
\]

После неё блок обновляется напрямую

\[
z_j^{t+1}
=
\frac{b_j}{a_j + \lambda^{t+1}}
\]

Дополнительной нормировки (z) после шага нет

Перед вычислением все коэффициенты одной строки делятся на общий масштаб
Сохранённое значение \(\lambda\) относится к этим безразмерным коэффициентам и потому не меняется при общем масштабировании \(a\) и \(b\)

Для самого первого шага начальное значение явно восстанавливается из текущего нормированного блока

\[
\lambda^0
=
\sum_j b_j - \sum_j a_j z_j^0
\]

После первого шага используются сохранённые множители предыдущей MM итерации

## Защита и наблюдаемость

Поправка ограничивается аналитическим интервалом существования корня чтобы знаменатели оставались положительными

Состояние множителей сохраняется в Lightning checkpoint и восстанавливается при продолжении обучения

В train метрики добавлены величины

- `simplex_beta_residual`
- `simplex_core_residual_max`
- `simplex_core_residual_mean`
- `simplex_newton_correction_max`

Первые три показывают фактическое отклонение обновлённых параметров от симплекса

Полный кандидат по прежнему фиксируется только после проверки неувеличения мажоранты и исходной функции
